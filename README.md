# Autom_working_companion

Este es un programa que se esta desarrollando para realizar una automatización de tareas simples
pero repetitivas en entornos de oficinas y trabajos administrativos.

# ALCANCE DEL PROYECTO

El alcance de todo el programa esta definido para mejorar las experiencias que los usuarios en entornos
corporativos exigentes requieren día a día para cumplir con sus tareas en la oficina, lo cual se traduce en 

    -1. Disminuir la carga de trabajo a través de aplicar funciones que permitan la automatización de generar reportes de excel.
    -2. Disminuir el tiempo de respuesta para la creación de graficas y exposiciones de kpis durante reuniones, tanto planificadas como sorpresivas, generando un trabajo eficiente y completo para con los clientes que los usuarios esten tratando.
    -3. Simplificar el ingreso de datos, generando reporterias de manera automática para su uso en reuniones y meets de resultados.
